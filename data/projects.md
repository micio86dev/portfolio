# Fiberdroid Customers area
## Laravel 9 + NuxtJS 2 web application (SPA)
### https://area-clienti.fiberdroid.it

Customer: Fiberdroid

The application is a PWA (SPA) connected to a REST API. It has many features including: a notification management system (push, websocket and mail), a system of user roles and permissions, automated management of invoices for end customers, management of appointments, shipments of products, management and flow of contracts and much more. The development is always in the process of innovations and improvements, but it already has a stable base, the result of a long programming period that started in 2021 and in addition to being well documented, it has integrated the Unit Tests for the core functions of the system.

# INspxt
## Laravel 9 REST API web application + Redis
### https://inspxt.tc2services.app

Customer: TC2 Group

App for the management of inspectors and the inspections they carry out. The REST API developed in Laravel manages user roles and permissions, mainly: administrators and inspectors. The front-end is developed in React and completely distinguishes the 2 user roles by showing a simplified interface for inspectors who can only have access to some features of the app. The system is stable and performing, given the access and data traffic it has to manage. It mainly manages inspection activities, certifying the quality of customer products. During the complete refactoring the UX was improved, the DB structure simplified, the data migrated to the new structure and the server-side code simplified both syntactically and logically.

# Silent Hill Web
## Laravel 10 REST API (upgraded to 12) + Redis + Reverb (Sockets) + NuxtJS 3 (upgraded to 4) SSR website + NuxtJS 2 backoffice (upgraded to 4 + shadcn total refactoring)
### https://silenthillweb.com

After the news about the release of new games in the saga I decided to develop a PWA in Nuxt 3 + Laravel 10 for my favorite game series. The app is developed with SSR support and improved in all aspects of accessibility and usability useful for SEO. It has a notification system to notify users of any event, interactive maps based on the image of the maps of the various games, it is divided into 2 menus (horizontal for game selection and vertical for subsections and generic sections). Users can register via email or via Facebook Login. The administration panel was developed in Nuxt 2 to speed up its development, it manages different user roles and related configurable permissions, images and youtube videos can be loaded quickly. Both site and panel are in multilingual: Italian, English and Spanish. I don't think there is currently a better site than Silent Hill around, only the content is missing since it is a totally non-profit project it is not easy to find collaborators (if you are interested and know Silent Hill well, contact me).

# DevBoards.io
## ElysiaJs/BunJs + QwikJs + Python 3.11 + MongoDB + Redis
### https://devboards.io

IT job discovery and tech news platform targeting the European and U.S. markets. It aggregates job listings from 10+ sources using AI-powered APIs, provides multilingual tech news, and includes a custom CMS admin dashboard for content management.

Two Python scripts import jobs every 12 hours via RSS feeds and public job portal APIs, filtering Tech/IT roles and automatically categorizing each listing with relevant metadata. Users can discover thousands of job opportunities daily through a single platform available in 5 languages, with fast search filters based on skills, availability, and seniority.

Each user receives a compatibility score for every job posting, while companies are assigned a trust score based on the quality of their job ads and a community-driven like/dislike rating system.
